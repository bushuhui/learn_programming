# C++11

详细介绍资料请阅读、学习C++11

* [C++11教程](c++11.md)
* [C++ Template](template.md)



C++ 11主要包括的内容：

* 关键字及新语法
    - auto关键字及用法
    - nullptr关键字及用法
    - for循环语法
* STL容器
	- std::array
	- std::forward_list
	- std::unordered_map
	- std::unordered_set
* 多线程
	- std::thread
	- std::atomic
	- std::condition_variable
* 智能指针内存管理
	- std::shared_ptr
	- std::weak_ptr
* 其他
	- std::function、std::bind封装可执行对象
	- lamda表达式
