# Stage 7 - 高级编程

主要学习C++ 11， C++14， C++20等最新功能、函数；学习并掌握AI编程的思路、技巧等。



## C++高级功能学习的思路

1. 学习[C++11](cpp11)的基本用法，可以使用《现代C++教程》或者《Effective C++》
2. 学习[STL](stl)
3. 使用[Svar](https://gitee.com/pi-lab/Svar)，并琢磨其中所使用的高级C++技巧
4. 学习G2O，Ceres等库中高级的C++技巧
5. 通过编写SLAM程序深刻体会C++高级用法的特性、用处



## AI编程

随着大语言模型快速发展，AI编写的代码质量越来越高，我们在掌握了基本的编程思路和技术的基础上，可以提出详细的需求描述，从而让AI帮我们完成具体的编码、测试等工作。
