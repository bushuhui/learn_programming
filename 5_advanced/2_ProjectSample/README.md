# 标准项目 - 示例

本目录包含了一个标准的示例项目，综合演示了如何将多种技术进行综合，从而更好的实现跨平台、部署方便、结构清晰、模块化等目标。

核心的目标：

* 程序里不要出现固定本机的路径、参数等。
* 如果需要读取数据文件，最好是相对路径，或者从配置里面读取。不需要修改程序就能在一个新的电脑上运行起来。
* 架构清晰，程序的每个模块功能都相对独立，各个模块之间通过设计好的接口来实现相互交换数据。
* 使用CMake等管理程序代码，方便在不同操作系统下编译。
* 合理的使用第三方库，哪些库可以直接包含在本项目，哪些库可以通过安装，需要斟酌。
* 可以编写一个或者多个启动脚本，在这个脚本里写入环境变量等，方便运行，并方便其他人快速入手。
